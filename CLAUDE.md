# CREW

Беговое социальное приложение, работающее в первую очередь как Telegram Mini App (плюс мобильные сборки через Capacitor). Карта для поиска компании на пробежку, лента постов, беговые клубы, интеграция со Strava.

## Стек

- Next.js 16 (Turbopack), React 19, TypeScript
- Prisma + PostgreSQL (`DATABASE_URL`/`DIRECT_URL` в `.env`)
- NextAuth — кастомный credentials-провайдер: обычный логин по паролю И отдельная ветка для входа через Telegram `initData` (см. `src/lib/auth.ts`)
- Yandex Object Storage (S3-совместимое) для медиа — картинки грузятся через сервер (`/api/upload`, со сжатием `browser-image-compression`), видео — напрямую в S3 по presigned URL (`/api/upload/presign`), в обход лимита тела запроса Vercel (~4.5MB)
- Capacitor (Android/iOS) — вторичный таргет, основной — Telegram WebView

## Важно: живого GPS-трекинга нет

Раньше было live-отслеживание пробежки в приложении — от него отказались, потому что Telegram глушит GPS при выключенном экране/свёрнутом приложении. Теперь пробежки приходят **только** через Strava API sync (`/api/strava/sync`, `/api/strava/webhook`). Не предлагать доработку live-трекинга, если явно не попросят.

## Разделы приложения

- **Карта** (`/`) — маячки на карте: соло (`RunProposal`) и клубные (`Event` с `showOnMap: true`). Создание/просмотр/редактирование маячка — один общий bottom sheet поверх карты, не отдельные страницы. Темп задаётся кастомным dual-thumb слайдером на Pointer Events (`src/components/PaceRangeSlider.tsx`) — сознательно не нативный `<input type="range">`, тот ненадёжно работал на тач-устройствах.
- **Лента** (`/feed`) — посты с текстом/фото/видео (до 10 вложений на пост), лайки, комментарии с вложениями. Карточки в стиле Threads/X.
- **Клуб** (`/club`) — клубы, участники, рейтинг по суммарной дистанции, клубные события с маршрутом (`MapRouteBuilder`, `MapPicker`).
- **Профиль** (`/profile`) — статистика, график активности, история пробежек (карточки как в `ProfileDashboard.tsx`).

## Дизайн-система

- Тёмная тема (только тёмная, светлой нет), фон чисто чёрный `#000000`.
- Один акцент — лайм `#CCFF00` (`--primary`).
- Карточки: `bg-card/40 backdrop-blur-md border border-white/5 rounded-[22px]`.
- Подписи полей форм: `text-[10px] font-bold text-muted uppercase tracking-widest` (не `text-xs`/`tracking-wider` — это разъезжается по размеру с остальным UI).
- Аватарки в ленте: автор поста 40px, автор комментария 36px, поле ввода ответа 36px (должны совпадать с комментаторами).
- Карусель из нескольких фото/видео в посте — тайлы фиксированного размера `w-[64%] aspect-[4/5] object-cover` (кроп), чтобы пик следующего слайда был одинаковым независимо от исходных пропорций фото — как в Threads. Одиночное фото/видео в посте **не кропается**, показывается в родных пропорциях.

## Хранение медиа (без миграции БД)

Колонка `mediaUrl` (Post и Comment) — строка: одиночное вложение — просто URL, несколько — JSON-массив `[{url, type}]`. Парсинг/сериализация — `src/components/MediaCarousel.tsx` (`parseMedia`/`serializeMedia`). При удалении поста/коммента чистить S3 через `deleteMediaFromS3` (а не старый `deleteImageFromS3` — тот не понимает JSON-массив).

## Инфраструктура вне репозитория (не видно из кода)

- CORS на бакете Yandex Object Storage настроен на `https://crew-gamma.vercel.app` и `http://localhost:3000` — нужен для прямой загрузки видео в S3 из браузера. Если появится кастомный домен или другой порт для дев-сервера — CORS-правило тоже надо обновить (через `PutBucketCorsCommand`, credentials в `.env`).
- `.env` содержит `DATABASE_URL`, `DIRECT_URL`, `NEXTAUTH_SECRET`, `STRAVA_CLIENT_ID/SECRET`. `YANDEX_S3_*` и `TELEGRAM_BOT_TOKEN` заданы только на Vercel — локально их нет, часть функций (аплоад медиа, вход через Telegram) может не работать в чистом локальном окружении без них.
- Возможна параллельная работа над репозиторием — другой ассистент или сам пользователь могут коммитить в это же время. Перед началом задачи стоит проверить `git log` на неожиданные свежие коммиты.

## Проверка перед коммитом

- `npx tsc --noEmit`
- `npm run build` (нужно сначала остановить dev-сервер — Prisma-движок блокирует файл при пересборке на Windows)
- Для визуальных изменений — реальная проверка в браузере (dev-сервер + `javascript_tool`/`computer`), с замерами через `getBoundingClientRect()`, а не на глаз. Клики по кнопкам в браузерном тестовом инструменте иногда промахиваются мимо цели — надёжнее логиниться прямым `fetch` к `/api/auth/callback/credentials`, а не кликом по форме.
